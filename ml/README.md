# AI Recommend モデル

## ルール
- 前日の差枚が+3,000枚を超えた台は狙わない
- 1311〜1316 と 2218(見世物小屋)は狙わない
- 目的: 推奨5台のうち、当日+3,000枚を超える台数を最大にする

## データ
- `vvv2_1y.csv`: slot-eye の詳細分析から取得した ヴァルヴレイヴ2 全台の日別データ(2025/11/05〜、date,machine,diff,games,bb,rb)
- 2026/10/10 に台配置が変わった(旧 1087〜1175 → 新 1311〜1386 と 2218)。特徴量は台ごとの自分の履歴と、その日の中での順位なので、配置をまたいでも学習に使える

## モデル(ml/predict3.py)
候補台(上のルールで除外した残り)の中で、次の4つの順位を同じ重みで足す。
1. 勾配ブースティング: 翌日+3,000枚超えの確率
2. 勾配ブースティング: 翌日+5,000枚超えの確率
3. 直近7日の回転数の少なさ
4. 連続マイナスの日数

特徴量は直近1〜9日の差枚・回転数・ボナ回数とその日の順位、ボーナス確率とRB比率、連続マイナス/プラス、前日の隣の台、台の長期のクセ、日付の末尾など(ml/features.py)。

## 検証(ウォークフォワード、2026/01/15〜11/21 の304日、14日ごとに再学習、ml/compare3.py)
上位5台に入った+3,000枚超えの台数(1日平均)
| 方法 | 全期間 | 1月〜 | 5月〜 | 8月〜 | 現配置 |
|---|---|---|---|---|---|
| 対象台からランダム | 0.89 | 0.89 | 0.93 | 0.87 | 0.96 |
| 回転数ワースト7日 | 1.02 | 1.04 | 1.10 | 0.92 | 1.05 |
| 旧モデル(+5000狙い) | 1.03 | 1.07 | 1.12 | 0.91 | 1.07 |
| **採用モデル** | **1.10** | **1.09** | **1.20** | **1.00** | **1.22** |

誤差は±0.05程度。8通りを比べて選んだので、実際の効き目は少し小さめと見る。
なお、7種類の部品の重みを総当たり(2,186通り)で前半に合わせると、後半では旧モデルと差がなくなった(ml/search3.py、過学習)。そのため重みは調整せず等重みにしている。

## 毎日の更新
1. `vvv2_1y.csv` に新しい日の行を追記
2. `python3 ml/predict3.py history`(10/10以降の各日の推奨を、その日より前のデータだけで計算し直して `ml/pred_history.json` に保存。約1分)
3. `python3 ml/predict3.py`(全データで学習して翌日の推奨を `ml/prediction.json` に出力)
4. `python3 ml/update_site.py index.html`
