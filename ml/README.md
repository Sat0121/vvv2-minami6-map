# おすすめ5台モデル

翌日に差枚+5000枚を超える台を予測し、上位5台を出す。

## データ
- `vvv2_1y.csv`: slot-eye の詳細分析から取得した ヴァルヴレイヴ2 全台の日別データ(2025/11/05〜、date,machine,diff,games,bb,rb)
- 2026/10/10 に台配置が変わった(旧 1087〜1175 → 新 1311〜1386 と 2218)。特徴量は台ごとの自分の履歴と、その日の中での順位なので、配置をまたいでも学習に使える

## モデル
ロジスティック回帰と勾配ブースティングの予測順位に、直近7日の回転数の少なさの順位を同じ重みで足す。

## 検証(ウォークフォワード、2026/01/15〜11/21 の304日、14日ごとに再学習)
| 方法 | 上位5台中の+5000枚台 | 平均差枚(その日の平均比) |
|---|---|---|
| ランダム | 0.53 | 0 |
| 回転数ワースト(7日) | 0.65 | +430 |
| ロジスティック回帰 | 0.67 | +284 |
| LR+GBM | 0.69 | +279 |
| **LR+GBM+回転数7日(採用)** | **0.74**(前半0.74/後半0.75/現配置0.88) | **+476** |

±0.05程度の誤差あり。9通りを比べて選んだので、実際の効き目はこれより少し小さめと見る。

## 毎日の更新
1. `vvv2_1y.csv` に新しい日の行を追記
2. `python3 ml/predict.py` (全データで再学習して翌日の順位を `ml/prediction.json` に出力)
3. `python3 ml/update_site.py index.html` (台マップのデータとおすすめ5台を更新)
4. 検証し直すときは `python3 ml/backtest.py` と `python3 ml/variants.py`
