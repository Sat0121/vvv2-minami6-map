# 南6条店 ヴァルヴレイヴ2 台マップ

プレイランドハッピー南6条店のヴァルヴレイヴ2(42台)の差枚・回転数を、台の配置図・台リスト・日付別で見るための単体HTMLツール。

- `index.html` をブラウザで開くだけで動く(ビルド不要)
- マップ: 期待度ヒートマップ(回転数ワースト1・2/差枚ワースト1・2 が根拠)、日別差枚、期間機械割
- 台: 狙い目ランキング(期待機械割順)、台ごとの成績
- 日付: 日別機械割と台×日付マトリクス

データ: 10/10〜11/18(11/07〜11/09は未取得)。狙い方別の機械割は slot-eye の過去90日集計(11/18時点)。
